## Organizations

### list

List all organizations you have access to.

```python
client.organizations.list(
    limit=10,
    cursor="abc123"
)
```

<ParamField path="limit" type="int" optional>
  Maximum number of items to return per page
</ParamField>

<ParamField path="cursor" type="str" optional>
  Pagination cursor for fetching the next page
</ParamField>

<ResponseField name="data" type="List[Organization]">
  List of organization objects
</ResponseField>

<ResponseField name="next_cursor" type="str | None">
  Cursor for the next page, or None if no more results
</ResponseField>

### create

Create a new organization.

```python

    name="Acme Corporation",
    description="Leading AI solutions provider",
    website="https://acme.com",
    industry="technology",
    email="contact@acme.com",
    phone="+1-555-0100",
    visibility="public"
)
```

<ParamField path="name" type="str" required>
  Name of the organization
</ParamField>

<ParamField path="description" type="str" optional>
  Description of the organization
</ParamField>

<ParamField path="logo" type="str" optional>

</ParamField>

<ParamField path="website" type="str" optional>
  Organization website URL
</ParamField>

<ParamField path="industry" type="str" optional>

</ParamField>

<ParamField path="email" type="str" optional>

</ParamField>

<ParamField path="phone" type="str" optional>

</ParamField>

<ResponseField name="slug" type="str">
  Generated unique slug identifier
</ResponseField>

<ResponseField name="name" type="str">
  Organization name
</ResponseField>

```python

    role="admin",

)
```

<ParamField path="slug" type="str" required>

</ParamField>

<ParamField path="search" type="str" optional>
  Search query to filter members by name or email
</ParamField>

<ParamField path="role" type="str" optional>

</ParamField>

<ParamField path="limit" type="int" optional>

<ParamField path="cursor" type="str" optional>

</ParamField>
